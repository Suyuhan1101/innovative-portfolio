# Academic 排版与课程蜂窝

2026-10-14。实现依据：academic-draft.md 与用户新增的「科目简写、蜂窝紧密排列、悬停查看全名」。

## 视觉方案

- 沿用已确定的纸色 #faf9f4、墨色 #11141c、绿色 #17492d、辅助灰 #69707b、分隔线 #d8d9d1；强调色 #b53b24 用于在修标记与链接。
- DM Serif Display 用于页内标题与课程简写；DM Sans 用于正文、全名、状态。正文沿用全站 16–18px 自适应字号。
- 蜂窝是本页主要视觉变化，其余内容用安静的图文排版。数学学习与学习故事并列，研究摘要配现有海报，下方集中展示全部 15 门课程。
- 蜂窝使用尖顶六边形，同排相邻，隔行错开半格；宽屏每行五格，小屏每行三格。格内仅显示 AP／JHU 等类别、课程简写及状态符号。
- 蜂窝旁的固定说明区展示当前科目全名、Completed／In progress 和已确认的补充信息。悬停、键盘聚焦、点击均可更新；手机说明区位于蜂窝下方，避免浮层越界。
- 焦点与选中格使用清晰的轮廓／反转色。状态同时有文字与符号，不只依赖颜色。切换说明只做短淡入，尊重减少动态效果设置。

## 页面顺序


研究数值使用约 2,000 份报告，95% 的版本与计算口径继续留在编辑记录。全部内部导航使用已有转场。
