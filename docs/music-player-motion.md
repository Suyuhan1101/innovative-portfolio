# 音乐播放器展开与收起

2026-10-14，本地实现完成。本轮沿用 Flower Dance；用户选择先完成动效，之后再挑选其他歌曲。

## 行为

- 点击小播放器封面、曲名或空白区域，展开当前栏目的浮动大播放器。播放／暂停和停止仍是独立按钮。
- 展开的样式复用 About Me 播放器，提供封面、署名、进度、时长和音量；右上角为收起按钮。
- 普通展开约 1.1 秒：卡片从小播放器的真实位置向上扩张，封面单独移动、放大，完整控制逐渐显现。
- 收起沿同一路径返回，使用反向缓动；重新测量小播放器的位置及尺寸，最后恢复真实控件与键盘焦点。
- 曲目、进度、播放状态与音量共用原来的音频实例；展开不会切换栏目或重新加载音源。
- Escape 或点击浮层外侧也会收起。从菜单／媒体弹窗展开时，只关闭播放器浮层，保留下面的覆盖层。
- 键盘焦点留在浮层内；较矮窗口允许滚动控制区域，收起按钮固定在右上角。
- 页面转场期间展开入口暂时禁用，播放／暂停仍可用。减少动态效果模式将动画压缩为约 0.12 秒。

## 实现

- `components/MusicPanel.tsx`：原生模态 dialog、卡片与封面动画、反向路径、焦点恢复、尺寸变化处理。
- `components/MusicPlayer.tsx`：复用的大播放器及可展开的小播放器。
- `components/PortfolioShell.tsx`：各栏目、菜单与媒体弹窗接入；浮层展开时暂停背景首页轮播。
- `app/about-me.css`：浮层、展开提示与移动端尺寸。

动画使用视觉快照衔接形状；快照不可交互，并从辅助技术中隐藏。实际播放仍由 `MusicProvider` 控制。主卡片与封面共用位置动画，小卡片文字不会被拉伸。

## 验证记录

真实浏览器 UI 操作确认：

- 播放中展开，只有一个 audio，时间从约 27.3 秒继续到 27.7 秒；在浮层里暂停、跳转进度与调整音量正常。
- 1280px 视口小播放器为 x843.135 / y812 / 370×70。收起后四项坐标、尺寸一致，焦点返回 Expand music player，滚动限制恢复。
- 展开中途立即按 Escape 可以反向收起；原小播放器恢复可见，无残留遮罩。
- 320、390px 浮层完整显示。320×500px 下控制区域可以滚动，收起按钮仍在 y26、44×44 的可见位置。
- 浮层打开时从桌面改变窗口宽度，重新测量位置；收起时使用新的小播放器尺寸。
- 菜单上展开，再 Escape 收起后菜单仍然打开，焦点返回菜单里的展开入口。
- 图片弹窗上展开时两个原生 dialog 打开；收起后只剩图片弹窗，音乐进度仍保留。
- 浮层打开时浏览器后退到 About Me，浮层关闭且无残留，音频仍只有一个且保持进度；前进回 Projects 正常。
- 开发预览 `qa-motion=reduced` 下可展开、收起和停止。
