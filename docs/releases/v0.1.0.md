# Portfolio v0.1.0

First release snapshot prepared on October 15, 2026 (America/New_York).

## Included

- Homepage, About Me, Academic, Projects, Skills, Gallery, Music and Community.
- Six independently addressable project and community case studies.
- Deep green card styling with a left-to-right hover reveal.
- Embedded presentation, piano and clinic video players; shared music playback controls.
- HIS 2.0 change guidelines and the clinic's institutional Tibet outreach photographs.
- Responsive layouts, keyboard navigation and reduced motion support.

The production build and TypeScript checks passed before this snapshot. The build generates 16 pages. Local screenshots and original uploads remain on the development computer; the prepared website assets are versioned in `public/`.

## Hosting

- GitHub: https://github.com/Suyuhan1101/innovative-portfolio
- Domain: https://yhansu.com
- Framework: Next.js (automatic Vercel detection).
- Install command: `npm ci`.
- Build command: `npm run build`.
- Output directory: leave at the framework default.
- No application environment variables are currently required.
