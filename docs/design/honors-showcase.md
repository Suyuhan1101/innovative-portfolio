# About Me 荣誉展厅

2026-10-15。用户要求奖项展示更花哨、华丽，并授权自行选择设计方向。

## 设计方向

以个人荣誉展柜为意象，沿用全站深绿色与 DM Serif Display / DM Sans 字体。金属奖章、边饰和扫光集中在此区域。文字始终左对齐，桌面采用宽幅重点奖项搭配大小不同的展位，手机自然堆叠。

| 色彩 | 用途 |
| --- | --- |
| `#102d22` | 深绿展墙 |
| `#17492d` | 与全站主色衔接 |
| `#d9be7c` | 香槟金边饰 |
| `#f1dfac` | 浅金奖章与标题细节 |
| `#f8f5e9` | 暖白展位 |
| `#18352a` | 浅色展位正文 |

```text
荣誉标题、年份范围                       金属奖杯徽章
FTC 团队荣誉：第三名奖牌 | 第二名奖牌（宽幅展位）
Director’s List                  USACO（半宽展位）
Conrad                NHS                AP Scholar
CITI 研究认证：三张证书
钢琴八级                         国画四级
```

## 取舍

用实际内容决定装饰：FTC 两枚奖牌对应两次 Inspire Award 名次，USACO 使用银色符号，CITI 用证书签章，艺术区的 08 / 04 对应已提供的等级。没有将全部条目做成同一种奖杯，也不添加虚构的官方标志、证书图片或获奖统计。

交互包括约 1.15 秒的鼠标扫光、轻微抬升和徽章转动。进入视口时，标题奖杯仅出现一次。没有循环闪光、自动旋转或新增播放声音；减少动效设置关闭所有新增动画和位移。装饰图形对辅助技术隐藏，全部名称、日期、名次和说明保持可直接阅读。

实现：`components/HonorsShowcase.tsx` 与 CSS Module；内容仍维护在 `content/about-me.ts`。不新增运行时依赖。
