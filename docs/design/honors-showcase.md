# About Me 荣誉蜂巢

2026-10-15。用户最新选择为蜂巢，替代中央奖杯和拖放网络。11 个奖项使用相同大小的六边形，不预选或突出某一个奖项。

## 设计方向

沿用深绿展墙、香槟金细边、DM Serif Display / DM Sans。桌面以四／三／四的三排六边形交错成蜂巢；手机改为两格／一格交替，保证短名称、图标与年份可读。类别分别使用金色、浅绿和暖铜色，仅区分荣誉、研究认证和音乐美术，不表示排名。

每格显示用户内容对应的图标、短名称与年份。没有官方徽标、夸大获奖事实或自动轮播。完整数据仍由 `content/about-me.ts` 的 `aboutHonors` 维护：6 个荣誉条目、3 个研究认证和 2 个艺术条目。

## 交互

- 悬停或键盘聚焦时，六边形由左至右平滑填充类别浅色；上方固定介绍区显示一句短说明。介绍区不覆盖蜂巢或拦截点击。Escape 恢复默认介绍。
- 点击、Enter 或 Space 在蜂巢下方展开完整名称、年份、类别与用户提供的说明。FTC 保留两次 Inspire Award 的赛事、年份和名次。
- 方向键可在所有六边形之间切换；Tab 保留原生按钮操作。打开详情后焦点移到详情区域，返回按钮恢复原奖项焦点与蜂巢视图。
- 不再使用拖放或中央奖杯。手机点击可直接查看详情，页面可正常触摸滚动。
- 没有循环闪动或新增声音；减少动效模式关闭颜色填充、渐显与平滑滚动，内容和键盘操作仍可用。

实现：`components/HonorsShowcase.tsx` 与 CSS Module。不新增运行时依赖。
