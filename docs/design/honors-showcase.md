# About Me 荣誉展厅

2026-10-15。用户先要求更华丽，随后明确改为中央奖杯、连线奖项图标、悬停短介绍、拖入奖杯查看详情，避免单个奖项占据过多视觉空间。以下为当前设计，替代原有宽幅 FTC 展位。

## 设计方向

以奖项网络为意象，沿用深绿、香槟金、DM Serif Display / DM Sans。11 个奖项符号保持同样大小，不预选任何奖项；细线连向中央奖杯。桌面采用椭圆环形，手机用两侧错列符号围绕奖杯，保持可点击尺寸和可读标签。

## 取舍

图标按机器人、学业、编程、创新、服务、认证、钢琴和绘画对应实际内容。颜色区分荣誉奖项、研究认证和音乐美术，不表示排名。中央奖杯为装饰和投放目标，没有冒充官方标志，也不添加新的获奖事实。

## 交互

- 悬停或键盘聚焦显示一句短介绍与年份，同时强调对应连线。Escape 可关闭短介绍。
- 使用 Pointer Events 与 pointer capture 实现拖动，符号和连线随指针移动。距离奖杯足够近时发光提示；松手展开详情。拖到空白处则归位，不打开详情。Escape 可取消正在进行的拖动。
- 拖动有 6px 阈值，拖动结束抑制随后的点击，避免取消拖动后误开详情。指针取消、capture 丢失与组件卸载均清理拖动状态。
- 点击、Enter 或 Space 同样打开详情；方向键可以在符号之间切换。手机可直接点击，只有符号区域限制触摸滚动，其余区域允许正常滚动。
- 详情展示完整名称、年份、类别和用户提供的说明，FTC 保留两次 Inspire Award 的赛事与名次。选中后移到详情区域并聚焦，返回按钮恢复原符号焦点和图形视图。
- 无循环闪烁或新增声音；减少动效模式关闭新增动画与过渡，拖放与点击依然工作。
