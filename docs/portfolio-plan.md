## 1. 网站目标与个人表达

首要访客是本科招生老师，申请方向是计算机科学、数据科学和应用数学。网站希望通过研究与技术作品呈现思考和动手能力，通过编程、音乐、旅行呈现完整、真实的 Yuhan Su。

代表项目是 Cincinnati Children's Hospital 志愿工作中的 ARDS 自由文本报告提取 pipeline。现有成果包括 schema 代码、pipeline 代码、poster PPT、演讲视频，以及用于 error analysis 的 LLM judge pipeline。处理规模是 2,000 份报告。

研究叙事围绕：初始包含定义 → 文献与导师修订 → 补充排除定义 → 独立 prompt 的 LLM judge → 指标与错误分析 → schema 迭代。当前描述没有提供人工参考标签；指标的具体名称、数值与验证依据需要由现有研究材料补充，不能把 LLM judge 的一致性直接写成已验证的临床准确性。

个人内容包括：为兴趣开发的密码保存小程序；钢琴、纯音乐、流行和抒情音乐；新疆 4,700 m 高山经历；迈阿密沼泽与鳄鱼；深圳赛龙舟、美食等旅行片段。

### 开场与轮播要求

每次打开网站都出现开场：暖白背景中央显示非常大的 welcome to my world；点击后，同一句文字缩小并移动到页眉左上角，首页内容从上往下依次显现。

站内导航不重播开场，包括菜单 Home 返回首页与栏目间跳转；这是用户已确认的规则。新打开或刷新页面仍显示开场。

显现顺序：页眉其余元素 → 个人介绍与轮播 → 七个功能块 → 研究项目。开场结束后启动轮播。

轮播共有七张图，下方恰好七个圆点；自动切换，也能点击圆点选择。按用户最新要求，播放顺序为人物照（雪山人物照） → 网球 → 乐团 → 水墨 → ARDS → 机器人 → 食物；前六张已指定，未提及的食物照保留为第七张。初始图为人物照，圆点顺序跟随播放清单。栏目导航与图片播放分别维护配置。轮播区参照首页约 1.56:1 的横向比例；完整主体的比例例外采用完整显示方式。

### 七个独立页面与点击转场

七个入口各自打开独立页面。从首页方块进入栏目时，按用户指定顺序执行；目标页的方块、标题与正文显现由七个栏目共用：

1. 鼠标进入方块范围，方块背景、文字和图标切换为对比色；移出则恢复。
2. 点击后，选中方块先固定在点击位置，暂停轮播。
3. 顶部页眉与选中方块保持可见，页面其他内容逐渐消失。
4. 其他内容消失后，方块移至目标页内容区的左侧上部。
5. 方块到位后，其右侧逐渐显现大标题。
6. 大标题显现后，下方正文按行依次出现。

详细路由、主题映射、转场顺序、初始参数与验收条件见 [交互规格](interaction-spec.md)。手机端延续方块在左、标题在右的关系，并根据宽度缩小方块与字号。

建议初始动效参数：开场文字迁移约 0.8–1.0 秒；首页内容显现总时长约 1 秒；轮播约每 5 秒切换。栏目转场分别控制其他内容淡出、方块移动、大标题显现和正文逐行显现。参数属于实现起点，需要在实际浏览器中调整。开场与栏目入口保留点击、触屏和键盘方式；减少动态效果偏好采用简化转场。

响应式规则建议：桌面保持七块横向均匀排列；较窄屏幕按宽度换行；手机使用两列，最后一个居中。首页图片与文字在手机上纵向排列。

## 3. 技术建议

以下记录按需求与两天期限确定的技术方案，并标明首轮实际采用的实现。

| 环节 | 建议 | 用途 |
| --- | --- | --- |

| 样式 | 统一组件类名的 CSS + 全局设计变量 | 持久布局、菜单与浮动方块共用同一套规则；首轮使用 app/portfolio.css，后续组件复杂时可拆分 Modules。 |

| 内容 | JSON／TypeScript 配置；后续可加 MDX | 首轮文字、路由与图片使用结构化内容，尚未引入 MDX。项目长文可随后加入。[MDX 文档](https://nextjs.org/docs/app/guides/mdx) |
| 媒体 | 可复用 Gallery、Video、YouTubeEmbed 组件 | 图片浏览、视频控件、YouTube 嵌入与 poster 展示。 |
| 发布 | GitHub + Vercel，用户已准备账号并关联项目 | 配合用户选择的文件维护方式；Git 提交可触发部署与预览，实际构建与首次部署需验证。[Git 部署文档](https://vercel.com/docs/git) |

内容由项目文件维护。当前功能通过前端与静态内容即可组织；后台和数据库不列入首版架构。

静态导出与普通 Next.js 部署的图片优化配置不同。如果采用静态导出，需同步落实图片预处理或自定义 loader；不能直接假定默认图片服务可用。部署方式将在账号与托管选择明确后落实。

域名接入按 Vercel 项目控制台提供的配置，在 Cloudflare 中设置相应记录，并验证 yhansu.com 的 HTTPS、独立页面直接访问与刷新。前段先检查域名与托管条件，上线时使用实际记录值。[自定义域名说明](https://vercel.com/docs/domains/working-with-domains/add-a-domain)

建议将组件、内容与素材分别管理：
