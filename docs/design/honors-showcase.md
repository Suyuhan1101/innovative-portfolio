# About Me 奖项蜂巢

2026-10-15。用户提供 Academic / Coursework 截图，明确选择同款米白、深绿细边与衬线字体。此设计替代深绿金色展墙。

## 视觉与布局

直接沿用 `CourseHoneycomb` / `AcademicPage.module.css` 的字体、颜色、六边形细边、填色选中态与两栏比例：左边蜂巢，右边竖分隔线后的详情。11 项仍保持等大，不预选某一项；桌面四／三／四交错排列，手机三列交错，详情在下方。

六边形内上方显示年份，中间为衬线短名称，下方的小圆点区分荣誉、研究认证与艺术。图例标注实际类别，没有把所有项目当成比赛奖项。手机对较长名称使用 FTC、GCP、HSR、CRC 等短名称，辅助名称和详情始终保留全名。

## 交互与内容

- 悬停、键盘聚焦或点击任何六边形，立刻切换同一区域的完整详情，选中格以深绿底、米白字显示。鼠标移开后保留当前内容，便于阅读。
- 原生按钮、Tab、Enter、Space 与方向键均可使用；选中状态通过 aria-pressed 暴露，详情使用 polite live region。不再跳转到展开区或移动焦点。
- 详情保留完整名称、类别、年份、说明；FTC 两次 Inspire Award 的赛事与名次完整列出。数据维护在 `content/about-me.ts`，没有新增获奖事实。
- 颜色与详情仅作短暂平滑过渡；站内 Reduced 关闭新增过渡与渐显。

实现：`components/HonorsShowcase.tsx` 与 CSS Module。不修改 Academic 页面，不新增运行时依赖。
