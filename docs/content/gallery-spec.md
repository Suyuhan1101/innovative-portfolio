## 媒体与性能

- 25 张 JPEG 备份到 `assets/originals/gallery/`，网页副本放在 `public/media/gallery/`；记录尺寸、来源、哈希与文件大小。
- 使用 Next/Image、正确 sizes、原生 lazy loading 和固定缩略图比例；不预加载全部大图。
- Gallery 复用全站原生 dialog，并传入当前过滤后的照片清单；支持上一张／下一张、左右方向键、Escape、关闭后焦点返回。已有首页／ARDS 海报查看器继续工作，音乐暂停入口也沿用全站实现。

- 栏目进入、页眉、菜单和返回首页沿用现有转场。过滤只做轻量淡入，并尊重 reduced motion。
